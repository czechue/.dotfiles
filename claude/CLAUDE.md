# Global instructions

Seed file for the clean Claude Code setup (`ccl`). Keep it short — anything that
lands here is loaded into every session in every repository. Project-specific
rules belong in that project's own `CLAUDE.md`.

## Tooling

- `rg` over `grep`, `fd` over `find`, `bat` over `cat`.
- `bun` for JS/TS, `uv` for Python.
- Units are metric; currency is usually PLN.

## Conventions

- Conventional commits: `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`.
